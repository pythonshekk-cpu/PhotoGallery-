# Фото Галерея — Android

Простой нативный проект галереи на Kotlin и Jetpack Compose.

## Возможности
- Выбор нескольких изображений через системный Android Photo Picker.
- Сетка фотографий 3×N.
- Просмотр фотографии на весь экран.
- Добавление и удаление из избранного.
- Отдельная вкладка «Избранное».

## Запуск
1. Откройте папку проекта в Android Studio (Giraffe или новее).
2. Дождитесь Gradle Sync.
3. Запустите приложение на устройстве или эмуляторе с Android 8.0+.

Для сборки APK: **Build → Build Bundle(s) / APK(s) → Build APK(s)**.

## Важно
Это стартовая версия: выбранные URI и избранное хранятся в состоянии интерфейса и не сохраняются надёжно после полного закрытия приложения. Для выпуска в Google Play следует добавить постоянное хранилище, обработку разрешений/доступа и тестирование на целевых версиях Android.
